# Политики конфиденциальности игр

Статический сайт на GitHub Pages: по странице на игру, общий стиль `assets/style.css`.

| Игра | Страница |
| --- | --- |
| Блокпост: Мерж против зомби / Checkpoint: Merge vs Zombies | `checkpoint-merge-vs-zombies/` |

## Как добавить игру

1. Скопировать папку `checkpoint-merge-vs-zombies/` под новым именем (латиница, через дефис — это часть адреса).
2. Поправить в `index.html` название, дату вступления в силу и раздел про данные (реклама, покупки, аналитика — что есть в игре).
3. Добавить строку в список на главной `index.html` и в таблицу выше.
4. Закоммитить и запушить — Pages обновится за минуту-две.

**Адрес страницы, зашитый в опубликованную игру, не менять** (не переименовывать папку): иначе ссылка в игре сломается. Правки текста — в той же папке, с новой датой.
